FAQ / DETALLES

Algunas dudas frecuentes, resueltas.

FAQ breve

Cuanto cuesta una web y como se define el precio?

Se define por alcance, complejidad y tiempos. Con el brief te comparto un rango claro y opciones segun presupuesto.

Que incluye exactamente la entrega final?

Incluye diseno, desarrollo responsive, optimizacion inicial, puesta en linea y una guia corta para gestionar el sitio.

Cuantas rondas de ajustes y revisiones hay?

Trabajamos con rondas de refinamiento pactadas para cerrar contenido y detalles sin estirar el proyecto de forma infinita.

Que pasa despues de entregar el sitio?

Tenes soporte de salida para estabilizar el lanzamiento y resolver ajustes menores del arranque.
